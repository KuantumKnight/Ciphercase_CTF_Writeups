# Buried Evidence

**Author:** KuantumKnight
**Category:** Forensics
**Difficulty:** Medium

A damaged SD card was recovered from a warehouse security camera.

Investigators believe one piece of evidence was intentionally deleted before
the card was seized.

Recover the deleted evidence and submit the flag contained within it.

**Flag format:** `CYS{...}`

Provided artifact: camera_sd.img

The image is a forensic copy. Work from a copy and avoid mounting it read/write.
