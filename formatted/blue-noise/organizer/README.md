# Blue Noise — Organizer Package

**Author:** KuantumKnight

The player-facing bundle is deliberately limited to `player/blue_noise.png`.
Everything else in this directory is organizer-only.

Contents:

- `solution/` — intended two-stage solve and answer token
- `hints/` — progressive hints for players
- `requirements/` — runtime and tool requirements
- `verifier/` — end-to-end package/evidence verifier
- `generator/` — reproducible player-bundle generator
- `assets/` — original image, QR, encoded image, note, and hidden archive
